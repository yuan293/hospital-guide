# 诊途 · 下载后怎么用（给评委 / 试用者）

> **一句话**：解压 → 双击 `start.cmd` → 浏览器自动用起来。**不需要安装任何软件。**

本文对应提交材料中的 `05-离线运行时-runtime.zip`（若你拿到的是已含 `.runtime/` 的完整包）。
若你只有源码、没有 `.runtime/`，请看第 5 节「没有 `.runtime` 怎么办」。

---

| 文件 | 说明 |

## 2. 三步跑起来（约 5 分钟，其中 4 分钟在解压）

### 第 1 步：解压，确认目录结构

解压后**目录必须长这样**（`.runtime` 与 `package.json` 在同一层）：

```
hospital-guide/          ← 你的项目目录
├── package.json         ← 必须和 .runtime 同级！
├── README.md
├── start.cmd            ← 双击这个
├── run.cmd
├── .runtime/            ← 关键：运行时全在这里
│   ├── node/node.exe    ← 便携版 Node
│   ├── ollama/ollama.exe
│   └── models/          ← 两个模型权重
├── data/
├── lib/
└── docs/
```

> ⚠️ **最常见的坑**：解压出**两层**同名目录（如 `hospital-guide/hospital-guide/`）。
> 如果 `start.cmd` 外面还套着一层文件夹，请**把里面那层挪出来**，让 `start.cmd` 直接可见。

### 第 2 步：双击 `start.cmd`

会弹出一个黑色命令行窗口。**看到这些内容就是对了**：

```
[runtime] 使用项目自带 Node：.runtime\node\node.exe
v22.22.2
Starting Hospital Guide...
Open the URL shown below in your browser.
Keep this window open. Press Ctrl+C to stop.
Checking local model service...
```

再等几秒（首次启动 Ollama 会慢一些），继续出现：

```
Ollama is ready.
Hospital Guide v0.9.9
Open: http://127.0.0.1:3210
Demo only. Ctrl+C to stop.
```

> 若第 6 行显示 `Ollama unavailable; rule mode remains available.`（而不是 `Ollama is ready.`），
> 说明本机没装 Ollama —— 应用照常可用（规则引擎独立运行），只是模型增强功能不可用。

> **这个窗口不要关**，关掉服务就停了。
> 首行显示 `使用项目自带 Node` 说明免安装生效；若显示 `使用系统已安装的 Node` 也正常（说明你本机有 Node）。

### 第 3 步：打开浏览器

地址栏输入窗口里给出的地址（默认 **http://127.0.0.1:3210**）。

**建议依次点这几个**：
1. **「▶ 30秒自动演示」** —— 一眼看懂产品做什么
2. **描述不适** → 输入「上腹痛、反酸」→ 看**红旗征安全确认被优先弹出**
3. **效果评测页** —— 看各指标分子/分母、失败案例、逐轮追问轨迹

到这里，**双模型复现已成功**（模型增强功能可用）。

## 3. 想验证"数字是真的"？跑一下验证链

**另开一个**命令行窗口（别关上面那个），进到项目目录：

```sh
run.cmd verify
```

> 有 npm 的话 `npm run verify` 完全等价；`run.cmd` 是给没装 npm 的人准备的（便携版只含 `node.exe`）。

**看到最后一行是这句，就是复现成功**：

```
全部通过（快速链），耗时 0.1 分钟。
```

其他可跑的：

| 命令 | 作用 | 预期 |
| --- | --- | --- |
| `run.cmd test` | 单元测试 | `# tests 87` / `# pass 87` / `# fail 0` |

| `run.cmd verify:full` | 完整链含双模型评测 | 约数分钟，6 组全绿 |

## 4. 常见问题

**Q：提示「未找到 Node.js，且本目录下也没有自带的便携版」？**
说明 `.runtime/node/` 缺失，或 `.runtime` 放错了层级。检查 `.runtime/node/node.exe` 是否存在、且 `.runtime` 与 `package.json` 同级。

**Q：浏览器打不开？**
先确认那个黑窗口还开着。端口被占用时程序会自动顺延，**以窗口里实际输出的地址为准**。

**Q：跑评测时输出「跳过（Ollama 不可用或模型未安装）」？**
说明 Ollama 当时没起来。**评测脚本不会自动拉起它**（这是刻意设计，避免静默造假）。解决办法：先双击 `start.cmd`，看到 `Ollama is ready.` 后**保持窗口开着**，再另开窗口跑评测。

**Q：双击 `start.cmd` 一闪而过？**
可能被杀软拦截。右键 → 以管理员身份运行，或先把项目目录加入白名单。也可在项目目录手动执行 `run.cmd` 看报错。

**Q：需要联网吗？**
**不需要**。模型与运行时都在 `.runtime` 里，全程离线可用。

**Q：需要显卡吗？**
不需要。没有 GPU 也能跑，只是模型推理慢一些（CPU 也能出结果）。规则引擎部分完全不依赖模型。

## 5. 没有 `.runtime` 怎么办（仅源码 / 非 Windows）

### 5.1 Windows 但没有 `.runtime`

1. 装 **Node.js 20+**：https://nodejs.org （下载 LTS，一路下一步）
2. 命令行执行 `node -v` 看到 `v20.x` 以上即可
3. **不需要 `npm install`**（本项目零运行时依赖）
4. 双击 `start.cmd` —— 此时走"系统 Node"分支
5. 界面功能、规则引擎、安全闸门**全部可用**；仅模型增强功能不可用（没有模型）

### 5.2 macOS / Linux

`.runtime/` 内是 **Windows 二进制**（`node.exe`、`ollama.exe`），macOS / Linux **无法直接使用**。需要：

1. 装 Node.js 20+（官网或 `brew install node` / `apt install nodejs`）
2. 装官方 Ollama：https://ollama.com
3. 拉取两个模型：
   ```sh
   ollama pull qwen2.5:7b
   ollama pull qwen2.5:1.5b
   ```
4. 在项目目录执行：
   ```sh
   npm test          # 预期 87/87
   npm run verify    # 预期「全部通过（快速链）」
   npm start         # 启动网页
   ```

规则引擎与安全闸门部分**不依赖模型**，在 macOS / Linux 上可完整验证。

## 6. 判定标准速查

| 你想验证的 | 怎么判定成功 |
| --- | --- |
| 能跑起来 | `/api/health` 或首页返回 `status: ok` / HTTP 200 |
| 双模型就绪 | `start.cmd` 窗口出现 `Ollama is ready.` |
| 规则引擎正确 | `run.cmd verify` 末行「全部通过（快速链）」 |
| 评测数字属实 | 与 `00-先读我-评委复现说明.pdf` 第 4.3 节表格一致或更优 |
| 证据可独立复算 | 报告内 `dataset.sha256` 与仓库文件重算一致 |

> 全部医院、科室、案例数据均为**虚构**，本项目是**本机运行的工程原型**，不能用于真实就医。
